Menedżer schowka dla macOS

Wszystko, co skopiujesz — pod jednym skrótem.

Trove zapamiętuje teksty, linki, obrazy, pliki i fragmenty kodu, które przechodzą przez schowek Twojego Maca. Naciskasz ⌘Space, wpisujesz dwie litery i wklejasz — a historia nigdy nie opuszcza Twojego komputera.

Pobierz dla macOS Kod źródłowy

Wersja 1.8 · Apple Silicon · podpisana i notaryzowana · licencja MIT

Schowek pamięta jedną rzecz. Ty potrzebujesz więcej.

macOS trzyma w schowku tylko ostatnią skopiowaną rzecz. Wystarczy jedno ⌘C za dużo i adres, fragment umowy czy polecenie z terminala przepada.

Rzeczy giną po drodze

Link z rana, numer faktury z wczoraj, kolor z makiety — wszystko, co skopiowałeś, jest w Trove, pogrupowane i z datą.

Twoje dane nie są towarem

Historia, indeks i pliki leżą w lokalnej bazie SQLite na Twoim dysku. Żadnego konta, synchronizacji ani telemetrii.

Szybko, nawet po latach

Historia nie ma limitu, a typowe wyszukiwanie w milionie wpisów trwa kilka milisekund. Nie musisz niczego sprzątać.

Funkcje

Jedno okno do wszystkiego, co kopiujesz

Paleta Trove otwiera się nad aplikacją, w której właśnie pracujesz. Z klawiatury wybierasz kategorię, szukasz i wklejasz — bez sięgania po mysz.

Historia schowka

Każdy typ treści, z podglądem

  • Tekst, linki, obrazy, pliki, kolory, kod i HTML — każdy z odpowiednim podglądem.
  • Ten sam wpis skopiowany kilka razy to jeden wiersz z licznikiem ×N i listą dat.
  • Enter wkleja wpis prosto do okna, z którego przyszedłeś; ⌘⇧V wkleja go jako czysty tekst.
  • Przypięte wpisy zostają na zawsze, nawet przy włączonym czyszczeniu historii.
Wyszukiwanie

Znajduje „wrzesień”, gdy wpiszesz „wrzesien”

Wyszukiwarka pełnotekstowa ignoruje polskie znaki diakrytyczne, także „ł”. Wpisujesz tak, jak Ci wygodnie, a wynik pojawia się, zanim skończysz słowo.

Filtr typu zawęża listę do samych linków, obrazów czy plików.

Aplikacje

Launcher, który rozumie skróty myślowe

Kategoria 1 to wszystkie zainstalowane aplikacje z ikonami. „vsc” znajdzie Visual Studio Code, „chrm” — Chrome. Świeżo zainstalowany program pojawia się na liście bez restartu.

Okna

Układanie okien jak w Rectangle

Połówki, ćwiartki, maksymalizacja i wyśrodkowanie — z palety albo globalnymi skrótami, np. ⌘⌥←. Trove przesuwa okno, w którym ostatnio pracowałeś, nawet jeśli paletę wywołałeś kliknięciem w pasku menu.

Czat

Model AI w osobnym oknie

Rozmowa z modelem od Anthropic, OpenAI, OpenRouter albo Z.ai — z Twoim własnym kluczem API. Odpowiedź spływa na bieżąco, z formatowaniem Markdown, tabelami i blokami kodu. Rozmowa żyje tylko w pamięci okna.

Otwierasz go klawiszem 5 albo ⌘K z palety.

Import

Przenieś historię z Raycasta lub SuperCmd

Trove importuje zaszyfrowany eksport .rayconfig z Raycasta oraz pliki JSON i CSV z Raycasta i SuperCmd. Import działa w całości lokalnie, a powtórzony nie tworzy duplikatów.

Sejf kluczy

Kategoria 3 pokazuje nazwy kluczy z Twojego prywatnego sejfu. Wartość trafia prosto do schowka i nie zapisuje się w historii.

Retencja na Twoich zasadach

Domyślnie historia jest nieograniczona. Możesz kazać Trove usuwać wpisy starsze niż N dni — przypięte zostają.

Żyje w pasku menu

Bez ikony w Docku i w ⌘Tab, chyba że ją włączysz. Z paska menu wstrzymasz też zapisywanie schowka.

Eksport i statystyki

Całą historię wyeksportujesz do folderu, a w ustawieniach zobaczysz, ile miejsca zajmuje baza i pliki.

Prywatność

Domyślnie: zero ruchu sieciowego

Treść schowka, zapytania i ścieżki nigdy nie trafiają do logów. Menedżery haseł oznaczają swoje wpisy jako poufne — Trove je pomija, zanim cokolwiek odczyta. Możesz też wykluczyć dowolne aplikacje.

Jak to działa

Cztery kroki, zero konfiguracji

  1. Zainstaluj

    Pobierz plik DMG z GitHub Releases i przeciągnij Trove do Aplikacji. Ikona pojawi się w pasku menu.

  2. Kopiuj jak zwykle

    Trove zapisuje w tle wszystko, co trafia do schowka — poza wykluczonymi aplikacjami i wpisami z menedżerów haseł.

  3. Przywołaj paletę

    ⌘Space otwiera paletę nad bieżącym oknem. Klawisze 1–5 wybierają kategorię, a samo pisanie przeszukuje historię.

  4. Wklej

    Enter wkleja wpis do okna, w którym byłeś. Za pierwszym razem macOS poprosi o uprawnienie Dostępności.

⌘Space domyślnie należy do Spotlight. Trove wykrywa ten konflikt i w ustawieniach oferuje przycisk, który zwalnia skrót — albo przywraca go Spotlightowi. Możesz też ustawić dowolną inną kombinację.

Galeria

Zrzuty ekranu

Prawdziwy interfejs Trove na fikcyjnych danych. Kliknij, aby powiększyć; strzałki przełączają zdjęcia. Aplikacja ma interfejs w języku angielskim.

Dla developerów

Rust, Tauri 2 i React

Rdzeń w Ruście (workspace z kilkunastu crate’ów), powłoka Tauri 2 i interfejs w React 19 z TypeScriptem. Dane w SQLite w trybie WAL z indeksem FTS5 i magazynem plików adresowanym treścią.

Stack

  • Rust 1.96
  • Tauri 2
  • SQLite · FTS5
  • React 19
  • TypeScript
  • Vite
  • Vitest
  • pnpm 10

Uruchomienie lokalne

Potrzebujesz macOS z Xcode Command Line Tools, Rusta 1.96 (przypiętego w rust-toolchain.toml), Node 22 i pnpm 10.33. Żadne zmienne środowiskowe nie są wymagane.

pnpm install

# podgląd interfejsu w przeglądarce, na syntetycznych danych
pnpm dev

# natywna aplikacja z osobną bazą deweloperską
TROVE_DATA_DIR="data/dev" pnpm tauri dev

Bramki jakości

cargo fmt --all --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
pnpm typecheck && pnpm test -- --run && pnpm build

Import z terminala

cargo run -p trove-import-cli -- analyze --source <katalog-lub-plik>
cargo run -p trove-import-cli -- import  --source <…> --data-dir data/dev

Porty dla Windows i Linuksa istnieją w kodzie, ale nie zostały jeszcze skompilowane ani uruchomione na tych systemach — dziś Trove to aplikacja dla macOS.
